# Application icon

Generated with the built-in image-generation tool. `AppIcon.png` is the original raster; `AppIcon.icns` packages the macOS icon sizes.

## Generation prompt

Use case: logo-brand. Asset type: final macOS application icon for Yoto Playlist Studio, a personal tool for music playlists and 16x16 pixel artwork. Create one polished app icon: a warm ivory rounded-square tile with a dark teal inset resembling a tiny pixel display, containing a very legible coral and golden pixel-art musical note, plus two subtle short playlist bars. Friendly, simple, distinctive, premium native Mac app feel, soft tactile depth, very restrained shadow. Centered, bold silhouette readable at 32 pixels. The rounded-square tile should occupy about 85 percent of the square canvas with transparent margins outside the tile. No text, letters, wordmarks, real company logos, mockup scene, extra icons, or watermark. True transparent background outside the tile.
